# Control catalog (AECX)

Catalog controls are optional extensions. They MUST NOT weaken the DAS-1(TM) core.

Format
- AECX-### Title
- Control statement
- Supplemental guidance
- Assessment objectives
- Assessment methods: Examine, Interview, Test
