# Mappings

Mappings translate DAS-1(TM) artifacts to other frameworks.
Mappings are informative.

Available mappings
- `nist-800-53-r5.md`: representative crosswalk from DAS-1 core controls to NIST SP 800-53 Rev. 5 controls.
- `regulated/hipaa.md`: DAS-1 to HIPAA (45 CFR Part 164).
- `regulated/soc2-tsc.md`: DAS-1 to SOC 2 Trust Services Criteria.
- `regulated/pci-dss-v4.md`: DAS-1 to PCI DSS v4.0.1.
- `regulated/fedramp-high.md`: DAS-1 to FedRAMP High enhancements, layered on `nist-800-53-r5.md`.
