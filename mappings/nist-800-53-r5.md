# DAS-1(TM) to NIST SP 800-53 Rev 5 crosswalk

Status: informative, draft (v0.001). Mappings translate DAS-1(TM) artifacts to
other frameworks; they are informative and do not change DAS-1 conformance.

## How to read this

- Each DAS-1 core control (AEC-01..AEC-12) is mapped to *representative* NIST SP
  800-53 Rev 5 controls, not an exhaustive set. A single AEC usually touches
  several 800-53 controls; only the closest anchors are listed.
- This is a directional crosswalk, not a certified equivalence. It does not
  substitute for control selection and tailoring against an organization's
  baseline (Low / Moderate / High) or for assessment under SP 800-53A.
- DAS-1 is a focused delegated-authority control set for AI and agent actions.
  It complements an 800-53 baseline; it does not replace one.

## Core crosswalk

| DAS-1 control | NIST SP 800-53 Rev 5 (representative) | Relationship |
|---|---|---|
| AEC-01 Tool catalog and ownership | CM-8 System Component Inventory; PM-5 System Inventory; CM-2 Baseline Configuration | DAS-1 narrows "components" to the agent's tool and connector surface and requires a named human owner per tool. |
| AEC-02 Least privilege and time bounding | AC-6 Least Privilege; AC-2 Account Management (temporary / time-bound enhancements); AC-3 Access Enforcement | DAS-1 adds an explicit time bound (TTL) to each grant, not only least privilege. |
| AEC-03 Human gating for high-risk actions | AC-3 Access Enforcement; CM-3 Configuration Change Control; CM-5 Access Restrictions for Change | DAS-1 binds the gate to risk class: R3/R4 actions require a recorded approver before execution. |
| AEC-04 Approval latency budget | (no direct control) partial: IR-4 Incident Handling, SI-4 System Monitoring (timeliness aspects) | An operational SLO on approval time. 800-53 has no latency-budget control; this is a DAS-1 addition. |
| AEC-05 Revocation kill switch and drill | AC-2 Account Management (disable/remove); IR-3 Incident Response Testing; AC-3 Access Enforcement | DAS-1 requires a tested revocation path plus a quarterly drill with a measured time-to-revoke. |
| AEC-06 Preflight plan and declared blast radius | CM-4 Impact Analyses; RA-3 Risk Assessment; CM-3 Configuration Change Control | DAS-1 makes a per-action preflight with a declared blast radius mandatory before execution. |
| AEC-07 Audit trail completeness | AU-2 Event Logging; AU-3 Content of Audit Records; AU-12 Audit Record Generation; AU-9 Protection of Audit Information | Strong overlap. DAS-1 additionally requires inputs and outputs to be captured per tool call. |
| AEC-08 Data class boundaries | RA-2 Security Categorization; AC-4 Information Flow Enforcement; SC-7 Boundary Protection; SC-28 Protection of Information at Rest | DAS-1 enforces declared data-class boundaries on agent reads, writes, and emissions. |
| AEC-09 Secrets lifecycle and rotation | IA-5 Authenticator Management; SC-12 Cryptographic Key Establishment and Management; SC-28 Protection of Information at Rest | Strong overlap on credential and key lifecycle. |
| AEC-10 Cost attribution and caps | (no direct control) partial: SC-6 Resource Availability | Cost governance for metered AI usage is largely outside 800-53; this is a DAS-1 addition. |
| AEC-11 Exceptions register and expiry | CA-5 Plan of Action and Milestones; RA-3 Risk Assessment | CA-5 (POA&M) is the closest analog. DAS-1 additionally mandates an expiry on every exception. |
| AEC-12 Tool-call incident annex and exercises | IR-8 Incident Response Plan; IR-4 Incident Handling; IR-3 Incident Response Testing; IR-6 Incident Reporting | Strong overlap. DAS-1 adds a tool-call-specific incident annex and an annual tabletop. |

## What DAS-1 adds beyond 800-53

- AEC-04 (approval latency budget) and AEC-10 (cost attribution and caps) have no
  clean 800-53 analog. They are operational controls specific to delegated,
  metered AI action. Treat them as DAS-1 additions, not coverage gaps.
- DAS-1's risk classes (R1..R4) and the R3/R4 human-gating contract give 800-53
  controls like AC-3, CM-3, and IR-4 a concrete trigger model for autonomous
  agent actions, which the baseline controls leave to organizational tailoring.

## What 800-53 covers that DAS-1 does not

DAS-1 is scoped to delegated authority over agent actions. An 800-53 baseline
additionally covers families that DAS-1 does not address, including AT (Awareness
and Training), PE (Physical and Environmental Protection), PS (Personnel
Security), MA (Maintenance), and the broader CP (Contingency Planning) family
beyond revocation. Use DAS-1 to harden the agent-authority layer on top of a
baseline, not as a baseline by itself.

## Caveat

Control identifiers and titles follow NIST SP 800-53 Rev 5. Verify the current
catalog and enhancement numbers against the published NIST source before relying
on this crosswalk for assessment or audit. This file is informative under the
DAS-1 mappings policy.
