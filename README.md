# Delegated Authority Standard(TM) (DAS-1(TM))

Maintained by Forged Culture. Brand hub: forgedculture.com

Canonical spec home: delegatedauthoritystandard.com
Short redirect: das1.ai


DAS-1(TM) defines minimum controls for delegated authority where systems can invoke tools, change state, access sensitive data, or incur material cost.
