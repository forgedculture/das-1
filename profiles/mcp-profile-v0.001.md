# MCP profile (DAS-1(TM)) v0.001 (Informative)

Goal
- Describe how MCP connectors SHOULD satisfy DAS-1(TM) core controls.

Minimum guidance
- Treat each MCP server/connector as a tool boundary that must be inventoried (AEC-01) and revocable (AEC-05).
- Require correlation IDs across tool requests and results (AEC-07).
- Gate high-risk actions (AEC-03) and require preflight plans (AEC-06).
